# Codice di condotta

Koinon esiste per far crescere le persone e farle collaborare. Chi partecipa, online o nelle quest dal vivo, si impegna a:

- trattare ogni persona con la stessa dignità, senza distinzioni di età, genere, origine, religione, orientamento, disabilità o condizione economica;
- criticare le idee, mai le persone;
- non usare il progetto per vendere, fare propaganda o raccogliere dati;
- rispettare la privacy altrui: niente foto, nomi o dati di altri senza consenso;
- segnalare comportamenti scorretti invece di rispondere con altri comportamenti scorretti.

Chi viola queste regole può essere escluso dalle quest collettive o dal progetto. Le segnalazioni si inviano aprendo una issue riservata o scrivendo ai responsabili indicati nel README.

Questo codice si ispira al [Contributor Covenant](https://www.contributor-covenant.org).
